### 🔹 Требование 2: Устанавливает Docker

**Где реализовано:** `roles/application/tasks/main.yml`

```yaml
# 1. Зависимости
- name: Install Docker prerequisites
  apt:
    name:
      - apt-transport-https
      - ca-certificates
      - curl
      - gnupg
      - lsb-release
    state: present

# 2. GPG-ключ
- name: Add Docker GPG key
  shell: |
    install -m 0755 -d /etc/apt/keyrings
    curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
    chmod a+r /etc/apt/keyrings/docker.asc
  args:
    creates: /etc/apt/keyrings/docker.asc

# 3. Репозиторий
- name: Add Docker repository
  shell: |
    echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" > /etc/apt/sources.list.d/docker.list
  args:
    creates: /etc/apt/sources.list.d/docker.list

# 4. Установка пакетов
- name: Install Docker and Docker Compose
  apt:
    name:
      - docker-ce
      - docker-ce-cli
      - containerd.io
      - docker-compose-plugin
    state: present
```

✅ **Статус:** Выполнено полностью (по официальной документации Docker).

```yaml
# Остановка старых контейнеров (очистка)
- name: Stop existing containers
  shell: |
    cd /opt/microservices && docker compose down 2>/dev/null
    docker rm -f $(docker ps -aq) 2>/dev/null
  ignore_errors: yes

# Запуск приложения
- name: Start microservices
  shell: cd /opt/microservices && docker compose up -d

# Ожидание старта сервисов
- name: Wait for services
  pause:
    seconds: 30

# Проверка статуса
- name: Show running containers
  shell: docker ps --format 'table {{.Names}}\t{{.Status}}'
  register: containers

- name: Display containers
  debug:
    var: containers.stdout_lines
```
