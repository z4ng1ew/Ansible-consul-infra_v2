#  Cобираем JAR для hotel-service

## Шаг 1 — Собираем JAR на хосте через Docker

```bash
cd ~/Ansible-consul-infra/src/services/hotel-service

# Собираем
docker run --rm \
  -v "$(pwd)":/app \
  -v "$HOME/.m2":/root/.m2 \
  -w /app \
  maven:3.8-openjdk-8 \
  mvn clean package -DskipTests

# Проверяем
ls -la target/*.jar
```

Скинь вывод — увидим имя JAR-файла.

Часть 3 — Стратегия сборки образов с Micrometer
Главный принцип: на хосте собрал → запушил в Docker Hub → на виртуалках docker pull.
Шаг 1. Установить локальный Docker Registry на хосте (опционально, но рекомендую)
Это твой собственный Docker Hub на хосте — образы не уходят в интернет, а лежат локально. Виртуалки качают по локальной сети 1 ГБ/сек, а не из интернета 1 МБ/сек.
bashsudo docker run -d -p 5000:5000 --restart=always --name registry registry:2

# Открыть порт в firewall
sudo firewall-cmd --add-port=5000/tcp --permanent
sudo firewall-cmd --reload
В виртуалках разрешить insecure registry (без TLS-сертификата — это локально, можно):
bash# На каждой ноде (manager/node01/node02):
ssh manager 'sudo bash -c "cat > /etc/docker/daemon.json << EOF
{
  \"insecure-registries\": [\"192.168.56.1:5000\"]
}
EOF
systemctl restart docker"'

# То же для node01, node02
Теперь пушить будешь так:
bashdocker tag МОЙ_ОБРАЗ 192.168.56.1:5000/МОЙ_ОБРАЗ
docker push 192.168.56.1:5000/МОЙ_ОБРАЗ
